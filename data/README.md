# 법률 학습 데이터 안내

이 폴더에는 배포·재이용 조건을 확인한 **법령·판결문 원문만** 추가합니다. 현재 패키지는 원문 데이터를 포함하지 않습니다.

- `statutes/`: 검증된 법령 원문
- `cases/`: 검증된 판결문 원문
- `sources.csv`: 파일별 출처 URL, 수집일, 재배포 허용 근거, 개인정보 검토 결과

민간 판례 해설·유료 DB 자료·개인정보 포함 문서는 별도 검토 없이 공개하지 마세요.

주의: 기존 `backend/ingest.py`, `graphrag_backend/ingest.py`는 이 폴더를 자동으로 읽지 않을 수 있습니다. 실행 전에 입력 경로를 확인해야 합니다.
